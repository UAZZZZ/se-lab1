# se-lab1

软件工程实验一：软件开发过程中的代码版本管理。

## 项目简介

本项目用于演示基于 Git 与 GitHub 的多人协作开发流程，包含远程仓库创建、
Issue 跟踪与指派、分支开发、Pull Request 代码评审、分支合并与清理等环节。

## 使用说明

1. 确保本机已安装 Python 3；
2. 在项目根目录执行：

   ```bash
   python hello.py
   ```

3. 终端将输出欢迎信息，表示仓库克隆与分支切换均正常。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `README.md` | 项目说明文档 |
| `hello.py` | 示例脚本，用于验证仓库克隆与 dev 分支开发是否成功 |

## 分支说明

- `main`：主分支，存放经过评审的稳定代码；
- `dev`：开发分支，由组员在本地创建并完成功能开发后推送。
